## The entry

> My father, a man of few words, told me on my wedding day: 'Say sorry first, even when you are right, because being right is a lonely room'.

One sentence, 139 characters, about the best advice I ever received — given by my father on my wedding day.

## How it works

`main.py` (pure Python standard library, no third-party packages) writes the sentence to `/output/entry.txt`. That is the whole program.

```sh
python3 main.py
cat /output/entry.txt
```
